# 07 快捷键、媒体键、HUD 与自动切换

Status: ready-for-agent
Blocked by: 03, 05

## 背景

快捷键目前直接调 `s.stepBrightness` / `s.stepVolume`（[shortcuts.go:41](../../../shortcuts.go#L41)），媒体键在 [mediakeys.go](../../../mediakeys.go) 与 `syncMediaKeys`，日夜自动切换在 `autoCheck`（[store.go:608](../../../store.go#L608)）里用一份 `prefs.AutoPeriod`。多屏后要明确"作用在哪台"。规则见 [spec](../spec.md#快捷键与媒体键)。

## 要做

1. 快捷键执行时作用于目标显示器；目标切换后，下一次按键就作用在新目标上。
2. 输入源快捷键：列表来自目标显示器的输入源；目标没有该输入源时不动作（不要退回"别的显示器有这个输入源"）。
3. macOS 媒体键：
   - 亮度键 → 目标显示器；
   - 音量键 → 声音实际输出所在的显示器，与目标不一致时仍调它；
   - 判断"声音输出在哪台"需要一个新查询（现有 `display.SoundToDisplay` 只回答"是否输出到显示器"），实现不了就先退化为"目标 + 提示"，并在 issue 里写明取舍。
4. HUD：多台时标题带显示器名；音量键调的不是目标时，HUD 显示被调的那台的名字。
5. 日夜自动切换：时间表全局，开关与日夜场景按显示器；每台各自记住"上次应用的时段"（`displayState` 里），到点各自切换，手动调整保留到下次交替。显示器重新接入时补齐当前时段。
6. 跟随内屏：按显示器的开关与范围；多台时各自缓动，注意每秒写入总量。

## 验收

- 目标 A 时按亮度加，只改 A；切到 B 再按，只改 B。
- 输入源快捷键：目标没有该输入源时无动作，也不弹错误。
- 声音在 A、目标 B：音量键调 A，HUD 显示 A 的名字。
- 两台都开自动切换：各自到点切换，互不影响；拔掉一台再插回，补齐当前时段。
- 单台时所有行为与 1.11.1 一致。

## 备注

`prefs.AutoPeriod` 是 v1 的单值，迁移时归给第一台外接（见 04），不要留在全局。

## Comments

- 2026-11-03：音量键按默认输出设备的名称匹配显示器（忽略大小写、空白、全半角与「显示器 / monitor」字样）；名称匹配不到、或两台同名无法判断时退回目标显示器。CoreAudio 没有公开「哪块屏幕在出声」的对应关系，`SoundOutputName` 是能做到的最好结果。
