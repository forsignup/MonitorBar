# 09 真机验收

Status: ready-for-human
Blocked by: 01, 02, 03, 04, 05, 06, 07

## 背景

Apple Silicon 上按 EDID 绑定 DDC 的方案只在**一台外接**的机器上验证过（M4 Pro，单显示器）。同型号、双外接、混合 DPI、热插拔与唤醒这些路径没法靠 CI 覆盖，必须真机跑。

## 验收清单

### macOS（Apple Silicon）

- [ ] 两台外接，都支持 DDC：`--probe` 两台都有读数；对 A 设亮度不影响 B；重启后各自保留。
- [ ] 两台外接，一台不支持 DDC：不支持的那台显示「仅软件调光」，另一台硬件控制正常，两者互不影响。
- [ ] 两台完全同型号、序列号为 0：切换器用「名称 · 接口」区分；DDC 配不上的那台不出现错误写入，另一台正常。
- [ ] 热插拔：运行中拔掉目标 → 自动回退；插回 → 恢复设置与选中。
- [ ] 睡眠唤醒：唤醒后 DDC 仍可用（没有卡住的陈旧 service），Gamma 按各自基线恢复。
- [ ] 内屏 + 两台外接：跟随内屏按台生效，各自范围不同也成立。

### macOS（Intel，如可得）

- [ ] 两台外接：framebuffer 路径按 EDID 匹配到各自的 I2C 总线，互不串台。

### Windows

- [ ] 两台外接，混合 DPI（100% + 150%）：面板位置、切换、亮度都正常。
- [ ] 两台外接：`monitorDevicePath` 身份稳定，重启后设置保留。
- [ ] 笔记本外接两台：内屏不作为目标，外接优先规则保持。

### 局域网

- [ ] 两台澎湃 OS、名称不同：自动配对，输入源与音量各自独立。
- [ ] 两台澎湃 OS、同名：配对卡片可选，重启后保持。
- [ ] 一台澎湃 OS：与 1.11.1 行为一致。

### 升级

- [ ] 从 1.11.1 升级：亮度、色温、网络地址落到第一台外接；快捷键键位保留。
- [ ] 回退到 1.11.1：全局项仍能读出（v2 文件不炸旧版本）。

## 备注

第 3 条与第 5 条是这次改动风险最高的两条。任何一条失败，先按 [ADR-0002](../../../docs/adr/0002-apple-silicon-ddc-binding.md) 的降级策略处理，不要临时改成贪心配对。
