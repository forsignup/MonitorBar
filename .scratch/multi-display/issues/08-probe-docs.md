# 08 命令行与文档

Status: ready-for-agent
Blocked by: 06, 07

## 背景

`--probe`（[probe.go:12](../../../probe.go)）只打印一台显示器；README 的「功能」「工作原理」「适配其他显示器」都建立在单台上。2.0 是对外可见的语义变化，需要写清楚。

## 要做

1. `--probe` 逐台打印：名称、接口、身份（含是否为位置键）、当前模式、原生分辨率、DDC 读数与能力、局域网设备与配对情况。输出保持中文，与现有风格一致。
2. README：
   - 「功能」补一段多屏：面板内切换、每台独立设置、屏幕时间仍是整机口径。
   - 「工作原理」补一句通道按显示器建立，以及 macOS 的绑定方式（不必展开私有 API）。
   - 「平台差异」补：Apple Silicon 多外接 DDC 依赖按 EDID 绑定，同型号无序列号时可能只有软件调光。
   - 新增「已知限制」：同型号且序列号为 0 的显示器换接口后设置不再匹配；DisplayLink/虚拟屏不出现。
3. `CHANGELOG.md` 写 2.0 的说明（应用内更新提示会显示它）。
4. 中英文案同步；`go tool mygo generate` 重新生成。

## 验收

- 两台外接时 `--probe` 输出两台，身份与配对可见。
- README 覆盖多屏、限制、macOS 差异；英文段落同步。
- CHANGELOG 与版本号一致，格式与历史条目一致。

## 备注

CHANGELOG 的语气沿用现有条目：先说新增能力，再说修复与限制，不写实现细节。
