# 屏幕时间保持整机口径

多屏之后几乎所有状态都按显示器拆开，屏幕时间是例外：它继续按"任一台被管理的显示器亮着就计时"统计，不按显示器分别记录。原因是这个数字回答的是"我今天在电脑前多久"，不是"这块面板亮了多久"；两块屏同时亮时若各自累计，就会得到两倍于真实时间的总和，而"总时长"在多屏下反而没有定义。保持整机口径也让 `usage.json` 与历史数据继续可比，升级不需要迁移。

## Considered Options

- **每台分别统计**：更细，但"总时长"失去定义，周柱状图的含义要重新解释。
- **每台 + 整机合计**：信息最全，但面板本来就只有一屏高，要同时解释两种口径。
- **按鼠标所在的那台统计**：贴近"专注在哪块屏"，但鼠标离开屏幕时统计会断，实现与解释都更复杂。

## Consequences

- 显示器拆下或休眠时，只要还有一台被管理的显示器亮着，计时继续。
- 内屏作为唯一目标时按内屏计时，与 1.11.1 行为一致。
